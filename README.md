# 4 The Heroes

4 The Heroes는 유명 로그라이크 게임인 ['For the King'](https://store.steampowered.com/app/527230/For_The_King/) 시리즈에서 많은 시스템을 참고하여 제작한 게임입니다.

- 기술 스택: Unity, C#
- 장르: RPG, 턴제 전투
- 개발 인원: 4인 -> 1인
- 개발 기간: 2024-01 ~ 2024-03 (4인, 약 3개월) / 2025-01 ~ 2025-07 (1인, 약 7개월)

# 게임 특징
## Area 탐험
![Area](https://github.com/user-attachments/assets/0cefc23c-a75b-46d8-af3e-ab328f52adf6)
- 플레이어는 Town에서 퀘스트를 받아 Area에 진입합니다.
- 플레이어는 Area를 탐험하며 전투를 통해 전리품을 모으고, 최종적으로 Area의 보스를 처치해야 합니다.

![Generate](https://github.com/user-attachments/assets/d26e1bea-1e3a-42f9-aa2e-40d5c67a5982)
- Area의 맵은 매 플레이마다 랜덤하게 생성됩니다.

## 턴제 전투
![Battle](https://github.com/user-attachments/assets/f568135e-d428-4a44-b834-7ff294e776e2)
- Area에서 전투 타일에 진입할 시 전투가 진행됩니다.
- 전투는 그리드 기반의 턴제로 진행됩니다.

## 마을(Town)과 재정비
![Town](https://github.com/user-attachments/assets/23864b14-d69d-49b6-9a95-4adf451e02ed)
- 플레이어는 Town에서 여러 재정비를 수행할 수 있습니다.
- 인벤토리 및 보유한 영웅을 확인하고 원하는 영웅들로 파티를 편성할 수 있습니다.
- 상점에서 아이템을 구입 또는 판매하고, 퀘스트 탭을 통해 Area에 진입할 수 있습니다.
